# cpp_llm_edu

Learning project for using coding agents (Claude Code, Codex, OpenCode) with C++.

## Quick start

```sh
scripts/check.sh
./build/debug/app/cpp_llm_edu_app Ada
```

## Agent setup

| Agent       | Reads                                                         |
|-------------|---------------------------------------------------------------|
| Codex       | `AGENTS.md`                                                   |
| OpenCode    | `AGENTS.md`, `opencode.json`, `.opencode/`                    |
| Claude Code | `CLAUDE.md` (imports `AGENTS.md`), `.claude/`                 |

Project rules live only in `AGENTS.md`.
